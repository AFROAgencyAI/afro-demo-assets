# afro-demo-assets

Optimized WebP images for AFRO client demos, served via jsDelivr.
Source JPEGs are hotlinked from client sites; these are size-reduced copies for LCP.

- `001-dana/` — Dr. Dana Goldberg homepage demo hero (laptop + mobile).
- `003-medam/` — Med Aesthetics Miami demo. 10 in-use images at the root with
  semantic names; `library/` holds the full 89-asset crawl by role, original
  filenames, for swapping later. One animated InMode badge stays .gif: as
  animated WebP it came out 46% larger.
